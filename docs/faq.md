# ❓ FAQ (Frequently Asked Questions) & Solusi Masalah

---

### 1. Saya sudah melakukan langkah-langkahnya, mengapa badge belum muncul di profil?
**Jawaban**:
Sistem background job GitHub membutuhkan waktu sinkronisasi. Badge biasanya muncul antara **10 menit hingga 24 jam**. Pastikan:
- Repositori tempat Anda beraksi berstatus **Public**.
- Email pada konfigurasi git (`git config user.email`) persis sama dengan email yang terdaftar dan terverifikasi di akun GitHub Anda.
- Jika akun Anda baru, tunggu minimal 1x24 jam untuk verifikasi antispam GitHub selesai.

---

### 2. Apakah saya bisa mendapatkan achievement di repositori Private?
**Jawaban**:
Sistem achievement GitHub mengutamakan aktivitas publik. Namun jika Anda bekerja di repositori private, buka **Settings** -> **Public Profile** -> centang opsi **"Include private contributions on my profile"**. Sebagian aksi seperti pull request merge tetap disarankan diuji di repositori publik agar pasti terdeteksi.

---

### 3. Mengapa badge saya tidak terlihat oleh orang lain yang melihat profil saya?
**Jawaban**:
Bisa jadi fitur showcase achievement Anda dinonaktifkan.
1. Masuk ke **Settings** -> **Public profile**.
2. Gulir ke bawah hingga bagian **Achievements**.
3. Pastikan kotak centang **"Show Achievements on my profile"** dalam kondisi dicentang.

---

### 4. Apakah akun saya bisa di-suspend karena membuat banyak PR untuk badge?
**Jawaban**:
GitHub melarang keras aktivitas spam otomatis ke repositori milik orang lain tanpa izin. Namun, jika Anda membuat dan menggabungkan PR di repositori milik Anda sendiri secara wajar, hal itu sepenuhnya legal dan aman.
