# 🎖️ Panduan Badge Tambahan Profil GitHub

Selain achievement berbasis aksi interaksi di repositori, profil GitHub juga menampilkan berbagai badge resmi lainnya yang menandakan keanggotaan program atau peran khusus:

---

## 1. GitHub PRO
- **Arti**: Akun memiliki langganan GitHub Pro berbayar atau akun terhubung dengan **GitHub Student Developer Pack**.
- **Cara Mendapatkan Gratis untuk Pelajar/Mahasiswa**:
  1. Kunjungi [GitHub Education](https://education.github.com/pack).
  2. Daftarkan diri menggunakan email kampus/sekolah berakhiran `.ac.id` atau `.edu`, atau unggah kartu tanda pelajar (KTM).
  3. Setelah disetujui, badge **PRO** warna emas/kuning akan langsung muncul di profil Anda, lengkap dengan akses GitHub Copilot gratis dan puluhan perk software lainnya!

---

## 2. GitHub Sponsor / Sponsored
- **Badge Pink Hati**: Muncul jika akun Anda telah disetujui sebagai penerima sponsor di program GitHub Sponsors, atau jika Anda aktif mensponsori developer lain.

---

## 3. GitHub Developer Program Member
- **Arti**: Pengembang yang terdaftar dalam program integrasi API GitHub.
- **Cara Bergabung**:
  1. Kunjungi [GitHub Developer Program](https://developer.github.com/program/).
  2. Daftarkan akun atau aplikasi OAuth/GitHub App yang Anda kembangkan.

---

## 4. GitHub Campus Expert
- **Arti**: Mahasiswa terpilih yang dilatih oleh GitHub untuk menjadi penggerak dan pemimpin komunitas teknologi di kampus mereka.
- **Cara Bergabung**: Mengikuti seleksi resmi GitHub Campus Expert yang dibuka secara berkala setiap tahun.

---

## 5. Security Bug Bounty Hunter
- **Arti**: Peneliti keamanan yang menemukan dan melaporkan kerentanan sistem di infrastruktur GitHub melalui platform HackerOne.
