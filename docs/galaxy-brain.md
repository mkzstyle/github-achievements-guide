# 🧠 Panduan Mendapatkan Achievement: Galaxy Brain

Achievement **Galaxy Brain** diberikan kepada pengguna yang memberikan jawaban yang ditandai sebagai **Accepted Answer** pada fitur GitHub Discussions di repositori publik.

---

## 🎯 Tingkatan (Tiers)

| Tingkat | Kriteria Jawaban Diterima | Tampilan Badge |
| :---: | :---: | :--- |
| **Tier 1 (Bronze)** | **2** accepted answers | Otak bercahaya perunggu |
| **Tier 2 (Silver / x2)** | **8** accepted answers | Otak bercahaya perak (x2) |
| **Tier 3 (Gold / x3)** | **16** accepted answers | Otak kosmik emas (x3) |
| **Tier 4 (Diamond / x4)** | **32** accepted answers | Otak galaksi penuh bintang (x4) |

---

## 🛠️ Langkah-Langkah Mendapatkannya

### 1. Mengaktifkan Fitur GitHub Discussions
1. Buka repositori publik Anda di GitHub.
2. Masuk ke tab **Settings**.
3. Di bagian **General**, gulir ke bawah ke bagian **Features**.
4. Centang kotak pilihan **Discussions**, lalu klik **Set up discussions**.

### 2. Mengajukan Pertanyaan di Kategori Q&A
1. Klik tab **Discussions** di menu navigasi repositori.
2. Klik tombol hijau **New discussion**.
3. Pilih kategori **Q&A** (kategori ini memiliki fitur centang accepted answer).
4. Buat judul pertanyaan teknis (misal: "Bagaimana cara konfigurasi Tailwind CSS v4?").
5. Klik **Start discussion**.

### 3. Memberikan Jawaban & Menandainya sebagai Accepted
1. Buka diskusi Q&A tersebut.
2. Tulis jawaban solutif di kolom komentar jawaban.
3. Pemilik repositori atau pembuat diskusi akan melihat tombol bertuliskan **Mark as answer** (ikon centang hijau) di pojok komentar jawaban.
4. Klik **Mark as answer**. Komentar tersebut akan disorot sebagai jawaban resmi yang diterima.
5. Ulangi proses ini sebanyak 2 kali untuk mencapai Tier 1 (Bronze), dan seterusnya hingga 32 kali untuk Tier 4.

---

## 💡 Tips & Etika Komunitas
- Berpartisipasilah secara aktif di repositori open source populer yang mengaktifkan GitHub Discussions (seperti Next.js, Vite, Supabase, Tailwind).
- Menjawab pertanyaan rekan pengembang secara nyata tidak hanya memberikan Anda badge, tetapi juga membangun reputasi profesional di GitHub!
