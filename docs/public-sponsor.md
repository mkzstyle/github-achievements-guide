# 💖 Panduan Mendapatkan Achievement: Public Sponsor

Achievement **Public Sponsor** diberikan kepada pengguna yang memberikan dukungan finansial kepada kontributor, pengembang independen, atau organisasi open source melalui platform resmi GitHub Sponsors.

---

## 🎯 Kriteria
- **Tingkatan**: Single Tier (1x)
- **Persyaratan**: Melakukan sponsor publik kepada setidaknya satu akun pengembang di GitHub Sponsors.

---

## 🛠️ Langkah-Langkah Mendapatkannya

1. Masuk ke GitHub dengan akun Anda.
2. Kunjungi repositori atau profil pengembang yang memiliki tombol **Sponsor** warna merah muda (pink) di profil mereka (misalnya pembuat framework, utility open-source, atau kreator tools favorit).
3. Klik tombol **Sponsor**.
4. Pilih paket sponsorship:
   - Banyak pengembang menyediakan opsi **One-time** (satu kali) sebesar **$1 USD**.
5. Di halaman konfirmasi pembayaran:
   - Pastikan Anda memilih visibilitas: **Public sponsor** (bukan private). Jika memilih private, badge tidak akan muncul di profil publik.
6. Selesaikan pembayaran menggunakan kartu debit/kredit yang mendukung transaksi internasional atau PayPal.
7. Badge hati **Public Sponsor** akan segera terpasang di profil Anda dan di halaman profil orang yang Anda dukung!
